Prix d'un call européen — Black-Scholes

Calculez le prix exact par la formule BSM.

Une action ne versant pas de dividende cote actuellement S = 48 USD. Vous analysez un call européen de strike K = 50 USD, d'échéance T = 0,5 an. Le taux sans risque est r = 5 % en continu et la volatilité annualisée est σ = 25 %.

Calculez le prix de ce call par le modèle Black-Scholes. Arrondissez à deux décimales.

S — Prix actuel 48,00 USD
K — Strike 50,00 USD
T — Échéance 0,5 an
r — Taux sans risque 5,00 %
σ — Volatilité 25,00 %
Indice

d₁ = [ln(S/K) + (r + σ²/2)·T] / (σ√T)  ·  d₂ = d₁ − σ√T

C = S·N(d₁) − K·e−rT·N(d₂)

Prix d'un call européen — Black-Scholes

S = 48 USD · K = 50 USD · T = 0,5 an · r = 5 % · σ = 25 %

✗  Incorrect
Votre réponse : 3,20 USD  ·  Bonne réponse : 3,05 USD  (tolérance ± 0,05 USD)
Solution détaillée 
σ√T = 0,25 × √0,5 = 0,25 × 0,70711 = 0,17678

d₁ = [ln(48/50) + (0,05 + 0,25²/2) × 0,5] / 0,17678
   = [ln(0,96) + (0,05 + 0,03125) × 0,5] / 0,17678
   = [−0,04082 + 0,04063] / 0,17678
   = −0,00019 / 0,17678
   = −0,0011

d₂ = d₁ − σ√T = −0,0011 − 0,17678 = −0,1779

N(d₁) = N(−0,0011) ≈ 0,4996
N(d₂) = N(−0,1779) ≈ 0,4294

C = S · N(d₁) − K · e^(−rT) · N(d₂)
  = 48 × 0,4996  −  50 × e^(−0,025) × 0,4294
  = 48 × 0,4996  −  50 × 0,97531 × 0,4294
  = 23,981  −  20,938
  = 3,04 USD  ≈  3,05 USD

Le call vaut 3,05 USD. S étant légèrement en dessous du strike (out-of-the-money), la valeur intrinsèque est nulle — le prix reflète uniquement la valeur temps.

Piège

Omettre le facteur d'actualisation e−rT sur le strike est l'erreur la plus fréquente. Sans ce facteur, on surévalue K de ≈ 1,24 USD sur cette maturité, ce qui conduit typiquement à une réponse autour de 1,80 USD.
